# KADR Cinema — учебный сайт кинотеатра

**Сайт:** https://kadr-cinema.onrender.com

Демо-проект: афиша и расписание → выбор сеанса → выбор мест (со схемой зала и 3D-видом с места) → регистрация/вход → демо-оплата → электронный билет с QR-кодом. Интерфейс на қазақша и русском.

## Запуск

Двойной щелчок по `run.bat` (при первом запуске сам создаст `.venv` и установит Flask), или вручную:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe server.py
```

Откройте http://127.0.0.1:5173. Для доступа с телефона в той же Wi-Fi сети: `server.py --lan`.

## Тестовые данные

- Аккаунт: зарегистрируйтесь на сайте (email и пароль от 8 символов с буквами и цифрами).
- Демо-карты (любой срок в будущем, любой CVC):
  - `4242 4242 4242 4242` — успешная оплата
  - `4000 0000 0000 0002` — банк отклоняет платёж

## Публикация в интернете (Render.com, бесплатно)

1. Войдите на https://render.com через GitHub.
2. **New → Blueprint** → выберите этот репозиторий → **Apply**. Настройки берутся из `render.yaml`.
3. Через 2–3 минуты сайт откроется по адресу вида `https://kadr-cinema.onrender.com`.

На бесплатном тарифе сайт «засыпает» без посетителей (первое открытие ~30–50 с), а база SQLite сбрасывается при каждом перезапуске — аккаунты и билеты не сохраняются надолго. Для постоянного хранения нужен платный диск или внешняя база данных.

## Админ-панель

Страница `#/admin` (ссылка появляется в меню и профиле у администратора): выручка и продажи, фильмы (добавить, изменить, скрыть; трейлер YouTube, постер, премьера), сеансы (добавить, отменить без проданных билетов, «освободить зал», цены сеанса), таблица цен.

Кто администратор — задаёт переменная окружения `ADMIN_EMAILS` (email через запятую). На Render: сервис → **Environment** → `ADMIN_EMAILS` = ваш email → Save, затем зарегистрируйтесь на сайте с этим email.

⚠️ На бесплатном Render база SQLite очищается при перезапуске — изменения админки и билеты временные. Для постоянного хранения нужна внешняя база (PostgreSQL) или платный диск.

## Избранное, напоминания, трейлеры

- ♡ — добавить фильм в избранное (список в профиле).
- «Напомнить о премьере» у фильмов в предпродаже: за день и в день премьеры на сайте появится уведомление (и системное уведомление браузера, если разрешено). Работает, когда пользователь открывает сайт; push-уведомления на закрытый браузер не реализованы.
- «Смотреть трейлер» — ссылка из админки или официальный трейлер с TMDB.

## Официальные постеры (TMDB)

Названия и описания фильмов — в `catalog.py`. Постеры и длительность сервер берёт с TMDB:

1. Зарегистрируйтесь на https://www.themoviedb.org/signup (бесплатно).
2. Settings → API → создайте ключ (тип Developer, некоммерческое использование).
3. Render → сервис **kadr-cinema** → **Environment** → добавьте переменную `TMDB_API_KEY` со значением ключа (подходит и «API Key», и «API Read Access Token») → **Save**. Сайт перезапустится сам.

Без ключа показываются нарисованные обложки. Внизу сайта выводится обязательная подпись TMDB. Для коммерческого использования (продажи сайта) у TMDB нужна отдельная лицензия.

## Поиск Google

В `static/` есть `robots.txt`, `sitemap.xml`, заголовок и описание страницы. Чтобы сайт быстрее попал в Google:

1. Откройте https://search.google.com/search-console → **Добавить ресурс** → «Префикс URL» → `https://kadr-cinema.onrender.com/`.
2. Подтвердите владение способом «HTML-тег»: строку `<meta name="google-site-verification" ...>` нужно добавить в `static/index.html`.
3. В разделе **Файлы Sitemap** укажите `sitemap.xml`.

Обычно сайт появляется в поиске по названию («KADR Cinema Қызылорда») через несколько дней — 2 недели.

## Телефон

Сайт адаптирован под экраны от 320 px: нижнее меню, прокручиваемая схема зала, крупные места. Его можно установить на телефон как приложение: в браузере «Добавить на главный экран».

## Как устроено

| Файл | Что внутри |
|---|---|
| `server.py` | Flask API: регистрация/вход (хеш паролей, сессии), расписание, занятые места, бронирование и демо-оплата, мои билеты |
| `catalog.py` | Вымышленные фильмы, залы, генерация расписания на 14 дней, цены (взрослый / детский / студенческий / VIP) |
| `static/app.js` | Одностраничное приложение: страницы, роутер, формы |
| `static/hall3d.js` | 3D-зал на three.js: пролёт камеры к месту, вид на экран |
| `static/i18n.js` | Тексты на казахском и русском |
| `instance/` | База SQLite и секретный ключ (создаются автоматически) |

## Важно: оплата и авторские права

- **Оплата демонстрационная.** Карта проверяется только по формату (алгоритм Луна, срок, CVC), деньги не списываются. Полный номер карты и CVC не сохраняются — только платёжная система и последние 4 цифры. Для настоящих платежей нужно подключать платёжного провайдера (Kaspi Pay, CloudPayments, Stripe и т. п.) по их документации — карточные данные тогда вводятся на стороне провайдера, а не на вашем сервере.
- **Без заимствований.** Название, логотип, фильмы, описания, постеры (рисуются кодом) и дизайн созданы для этого проекта. С чужих сайтов не скопированы ни тексты, ни изображения, ни фирменный стиль; общие для всех кинотеатров вещи (расписание, типы билетов, схема зала) — это стандартная функциональность, а не чужая собственность.
- Если захотите показывать настоящие фильмы — постеры и трейлеры защищены авторским правом, их можно брать только из официальных пресс-материалов дистрибьютора или по лицензии (например, через API TMDB с указанием источника).
